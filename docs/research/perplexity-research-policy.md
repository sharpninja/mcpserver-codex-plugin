# Perplexity Research Policy

Perplexity is the preferred external research provider for implementation planning and substantive documentation work that depends on current external facts.

## Required behavior

- Research official documentation and primary sources first.
- Record material source URLs in plans and substantive documentation.
- Separate verified facts, repository observations, assumptions, and recommendations.
- Do not send secrets, credentials, private configuration, customer data, or unnecessary proprietary code to external research providers.
- Do not begin implementation for non-trivial work until the written plan has been reviewed and approved.

## Fallback behavior

If Perplexity is unavailable, use the project's documented fallback research process and clearly mark the resulting plan or document as using fallback research.
